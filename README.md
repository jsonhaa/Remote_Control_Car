# Remote_Control_Car
Remote Control Car controlled via IR remote and sensor

IR Library requires Version 2.6.0

Motor Driver Models
1. L298N
2. YFROBOT PM-R3

Demonstration Video: https://youtube.com/shorts/S5rXyjdSgPQ
